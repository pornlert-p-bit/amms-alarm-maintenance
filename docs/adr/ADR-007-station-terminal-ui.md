# ADR-007 — หน้าจอแบบ "Station terminal" ตามแนว ISA-101

| | |
|---|---|
| **สถานะ** | Accepted |
| **วันที่** | 26 กันยายน 2569 |
| **ผู้ตัดสินใจ** | ผู้พัฒนา (เลือกจากตัวเลือก 6 แบบ) |
| **เกี่ยวข้องกับ** | [ADR-004](ADR-004-plc-integration-boundary.md) · NFR-USE-01 |

## Context

- ระบบนี้ใช้ในงานซ่อมบำรุงเครื่องจักร ผู้ใช้หลักคือช่างและวิศวกรที่ต้องเห็น "สิ่งผิดปกติ" ให้เร็วที่สุด
- หน้าจอแบบ Admin Dashboard ทั่วไป (เมนูซ้าย + แถวการ์ดตัวเลข + ตาราง) ระบายสีทุกสถานะเท่ากัน ทำให้ Alarm ที่สำคัญจริงไม่เด่น
- ผู้พัฒนามีภาษาการออกแบบของตัวเองจากงานก่อนหน้า (One Card Station — เครื่องเทอร์มินัลหน้างาน) และต้องการให้หน้าตาระบบนี้เป็นของตัวเอง ไม่ซ้ำกับแบบสำเร็จรูป

## Decision

ใช้โครงหน้าแบบ **Station terminal**:

1. **แถบบนสีเข้ม** มีชื่อระบบ เมนู และผู้ใช้ — **ไม่มีเมนูด้านซ้าย**
2. **แถวป้ายสถานะ** แบบคู่ "หัวข้อ | ค่า" เช่น `ฐานข้อมูล | ONLINE`, `PLC | SIMULATOR`, `กะ | เช้า` และนาฬิกาเวลาไทย
3. **เนื้อหาอยู่ในกรอบที่มีหัวข้อฝังบนเส้นขอบ** (group box) บนพื้นเทาอ่อน
4. **ตัวเลข รหัส และเวลาใช้ฟอนต์ monospace** เพื่อให้หลักตรงกันและอ่านเทียบกันง่าย
5. **หลักการสีตามมาตรฐาน ISA-101** (มาตรฐานการออกแบบหน้าจอ HMI ในโรงงาน): สถานะปกติเป็นเทา/ขาว และใช้สีเฉพาะเมื่อผิดปกติ — แดงสำหรับ Alarm และส้มสำหรับกำลังซ่อม ส่วนสีน้ำเงินใช้เป็นสีของปุ่มหลักเท่านั้น
6. **ป้ายสถานะต้องแสดงความจริง** — `ฐานข้อมูล ONLINE` แสดงเมื่ออ่านข้อมูลผู้ใช้จากฐานข้อมูลได้จริง และ `PLC` แสดงเป็น `SIMULATOR` สีเทา เพราะ v1 ยังไม่เชื่อม PLC จริง (ADR-004)

ชุดสีต่อยอดจาก One Card และปรับ 3 สีให้ผ่านเกณฑ์ความต่างของสี WCAG 4.5:1 (รายละเอียดใน `app/globals.css`) ฟอนต์หลักคือ Anuphan

## Alternatives ที่พิจารณา

| ทางเลือก | เหตุที่ไม่เลือก |
|---|---|
| Admin dashboard ทั่วไป (เมนูซ้าย + การ์ด KPI) | ทุกสถานะมีสีเท่ากัน Alarm จึงไม่เด่น และเป็นหน้าตาสำเร็จรูปที่พบได้ทั่วไป |
| ห้องควบคุมพื้นมืดทั้งจอ | อ่านยากเมื่ออัดวิดีโอหรือฉายโปรเจกเตอร์ และใกล้เคียงแบบ SCADA ทั่วไป |
| บอร์ด Kanban ทั้งระบบ | เหมาะกับหน้างานซ่อมหน้าเดียว ไม่เหมาะกับข้อมูลตารางของ Machine/Alarm (อาจนำมาใช้เฉพาะหน้างานซ่อม) |
| แอปมือถือเป็นหลัก | ตารางข้อมูลเยอะใช้งานบนมือถือยาก — แต่ยังทำให้แบบที่เลือกใช้บนมือถือได้ (ทดสอบที่ความกว้าง 320px แล้ว) |

## Consequences

**ผลบวก**
- Alarm ที่ยังไม่ปิดเด่นทันทีเพราะเป็นสีเดียวบนจอที่เป็นเทา
- ใช้ภาษาการออกแบบของผู้พัฒนาเอง ซึ่งอธิบายที่มาได้
- ไม่มีเมนูซ้าย พื้นที่แนวนอนจึงเหลือให้ตารางข้อมูลมากขึ้น

**ผลลบ / สิ่งที่ต้องเฝ้าระวัง**
- เมนูด้านบนรองรับเมนูได้จำกัด ถ้าเกิน 7–8 รายการต้องจัดกลุ่มใหม่ (ปัจจุบันมี 5)
- กรอบมีหัวข้อใช้พื้นหลังไล่สีสองท่อนให้กลืนกับพื้นด้านนอก ถ้าวาง GroupBox บนพื้นสีอื่นที่ไม่ใช่ `ground` ต้องปรับ `.groupbox-title` ใน `app/globals.css`
- ต้องระวังไม่ให้ใช้สีแดง/ส้มกับสิ่งที่ไม่ได้ผิดปกติ เพราะจะทำลายหลัก ISA-101
