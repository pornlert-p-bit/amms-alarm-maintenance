| R3 | ยกตัวเองเป็น admin | 0 แถว (RLS) | ✅ |

**admin ก่อนรัน migration 007** (ทดสอบด้วยค่าเดิม ข้อมูลไม่เปลี่ยนจริง):

**admin หลังรัน migration 007:**

| ID | ทดสอบ | ผลที่ได้ | สรุป |
|---|---|---|---|
| G1 | แก้ `full_name` ของผู้ใช้อื่น | `403 permission denied` | ✅ |
| G2 | แก้ `created_at` | `403 permission denied` | ✅ |
| G3 | แก้ `id` | `403 permission denied` | ✅ |

ตรวจหลังทดสอบ: ข้อมูลของ viewer (ชื่อ, วันที่สร้าง, Role) เหมือนก่อนทดสอบ และจำนวนโปรไฟล์ยังเป็น 3
