# รายงานผลทดสอบ — PLC Simulator

**วันที่ทดสอบ:** 27 กันยายน 2569
**สภาพแวดล้อม:** Production build ในเครื่อง (`next start`, `localhost:3100`) ต่อกับ Supabase project จริง
**บัญชีที่ใช้:** admin และ technician — ผู้ใช้กรอกรหัสผ่านเอง
**Migration:** 009 (PLC simulator)
**อ้างอิง:** ADR-004, REQ-BON-09

## ที่มา

ป้าย "PLC | SIMULATOR" บนแถบด้านบนมีมาตั้งแต่ทำธีมหน้าจอ แต่**ยังไม่มีตัวจำลองอยู่จริง** ผู้พัฒนาถามว่าป้ายนี้คืออะไร จึงพบว่าป้ายบอกเกินความจริง (หน้า `/simulator` ที่วางแผนไว้ใน ADR-004 ไม่เคยถูกสร้าง) — เลือกสร้างให้ครบแทนการลบป้าย

## Unit test

144/144 ผ่าน — เพิ่ม `tests/simulator.test.ts` (รายการ Fault ตามประเภทเครื่อง, เลือก Fault จากลำดับที่ส่งมาเท่านั้น, สถานะที่จำลองได้) และกรณี `/simulator` เฉพาะ Admin ใน `tests/roles.test.ts`

## แก้ระหว่างทดสอบ

- ข้อความหลังส่งสัญญาณขึ้น "Running" ไม่ตรงกับปุ่ม "RUN" → เปลี่ยนเป็นรหัสเดียวกับปุ่ม

## ข้อมูลทดสอบ

Alarm R-410 (จำลอง) ที่เกิดจาก S3 ปิดแล้วด้วยสาเหตุ "ทดสอบ PLC Simulator — ไม่ใช่เหตุการณ์จริง" และ M-004 กลับเป็น RUN — ข้อมูลกลับเป็น Alarm ค้าง 3 รายการเหมือนก่อนทดสอบ

## ข้อจำกัด

- ยังไม่มี PLC Gateway จริง — ฟังก์ชันในฐานข้อมูลเป็นจุดที่ Gateway จะเรียกใน v2 (ต้องเพิ่มบัญชีเฉพาะของ Gateway และตั้งแหล่งที่มาเป็น `plc`)
- ผู้ใช้ที่เป็น staff ยังใส่ `event_id` ขึ้นต้น `sim-` ให้ Alarm ที่บันทึกเองผ่าน API ได้ (ผลแค่ติดป้าย "จำลอง" ผิด ไม่กระทบข้อมูลอื่น)
