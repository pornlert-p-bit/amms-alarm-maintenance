## ข้อจำกัดที่ยอมรับ (ADR-005 Revision 2)

ผู้ใช้ยังเพิ่ม log "ในนามตัวเอง" ที่ไม่ได้เกิดจากการกระทำจริงได้ แต่ปลอมเป็นคนอื่น ปลอม Role ปลอมเวลา แก้ หรือลบไม่ได้

## ข้อมูลทดสอบที่ต้องเก็บกวาด

**ลบแล้ว** (ผู้ใช้รันใน SQL Editor ได้ 2 แถว, หน้า Audit Log เหลือ 32 รายการ ไม่มี `probe.*`) — log ทดสอบ 2 แถว (`probe.audit_spoof_before`, `probe.audit_spoof_after`) — ไม่มีใครลบผ่านเว็บ/API ได้ ต้องลบใน SQL Editor:

```sql
delete from audit_logs where action like 'probe.%' returning action, created_at;
```
