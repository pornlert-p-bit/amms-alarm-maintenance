## ข้อสังเกต (ไม่ใช่ข้อบกพร่อง)

- เครื่องที่มี Alarm ค้างยังมีสถานะ RUN ได้ เพราะสถานะเครื่องเปลี่ยนด้วยมือ (v1 ยังไม่มี PLC — ADR-004) ผังจึงแสดงป้าย "Alarm ค้าง" แยกจากสถานะเครื่อง
- ข้อมูลตัวอย่างทั้งหมดเกิดวันเดียวกัน กราฟจึงมีแท่งเดียว — ถ้าต้องการให้วิดีโอนำเสนอดูสมจริง ควรเพิ่ม Alarm ย้อนหลังหลายวันผ่าน SQL (ดู RUNBOOK)
