## ทดสอบความปลอดภัย: ยิง Data API ตรงด้วย session ของ technician

**ก่อนรัน migration 005:** ยิง `PATCH action_taken` ใส่ใบงานที่ยังไม่เสร็จ → **สำเร็จ (200)** แปลว่า API ยังเขียนผลการซ่อมปลอมได้ (คืนค่าเป็น null ทันทีหลังทดสอบ) — ยืนยันว่าต้องมี migration 005

## ยังไม่ได้ทดสอบ

- เปิดบอร์ดด้วยบัญชี **viewer** (ต้องเห็นบอร์ดแต่ไม่มีปุ่ม) — โค้ดซ่อนปุ่มด้วย `isStaff()` และหน้าเปิด/แก้ใบงานใช้ `requireStaff()` เหมือน Module Alarm ที่ทดสอบแล้ว แต่ยังไม่ได้ลองกับหน้านี้จริง
- การแข่งกดพร้อมกัน 2 คน (โค้ดกันไว้ด้วยเงื่อนไข `.eq("status", from)` ตอน UPDATE)
